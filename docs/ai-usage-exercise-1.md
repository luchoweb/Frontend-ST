# AI Usage - Exercise 1

This document explains how AI contributed to Exercise 1 (Personal Creative Portfolio).

## Scope

Exercise 1 requires a responsive SPA portfolio backed by Strapi, including component structure, styling, and one unit test.

## AI-assisted contributions

- Proposed a monorepo layout with separated backend and frontend responsibilities.
- Suggested a Strapi content model for portfolio sections (`hero`, `about`, `skill`, `project`, `contact`) and products-page copy.
- Helped scaffold React route composition and reusable UI components for the portfolio.
- Assisted with mobile-first styling structure and design token organization.
- Helped define a clean service-layer separation to keep API details outside page components.
- Supported documentation drafting and consistency checks for deliverables.

## Human review and decisions

- Reviewed generated code for naming clarity, duplication, and maintainability.
- Kept implementation JavaScript-only to match assessment scope.
- Validated responsive behavior and section structure manually.
- Confirmed local-run requirements and documentation completeness.

## Notes

This project is local-only for assessment purposes; no production/deployment claims are made.
